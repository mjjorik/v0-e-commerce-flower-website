Boston local relevance, florist expertise).

## Import
1. WordPress admin → **Tools → Import → WordPress** (install the importer if prompted).
2. Upload `docs/journal-articles-2026.wordpress.xml`.
3. Assign the author to yourself (or keep "Marco Reyes"), check **"Download and import file attachments"** is not needed (no images embedded), run import.
4. **Delete the default "Hello World" post** (Posts → Trash it) so the journal stays a clean feature + 6 (3×2 desktop / 2×3 mobile, no gaps).
5. Optional: set a Featured Image on each post — the journal cards and Article schema use it. Without one, the theme shows its botanical placeholder.

## What's included per article
- Title, slug, meta description (excerpt), category
- Clean semantic HTML body with a comparison table and a 3-question FAQ
- Author byline (E-E-A-T). Article + Breadcrumb JSON-LD is emitted by the theme.
